# Amendment Audit Note

This note records the September 2026 audit pass for the standalone Legal Metrology Rules Engine.

## Rule 26

G.S.R. 881(E), dated 2 December 2025, brought the pan-masala exclusion from Rule 26(a) into force on 1 February 2026. The engine must therefore evaluate this provision against the inspection date rather than applying the 2026 position to historical inspections.

## Rule 6(10A)

G.S.R. 128(E) inserted the e-commerce country-of-origin filter requirement from 1 July 2026. The Second Amendment Rules, 2026 subsequently substituted Rule 6(10A) and set the operative requirement from 1 July 2027. The engine's current effective-date gate uses 1 July 2027.

## Rule 27

G.S.R. 418(E), dated 29 May 2026, is recorded as the amendment source for the current Rule 27 evaluator. Findings concerning amended Rule 27 particulars should retain the amendment source alongside the principal Rules source.

This document is an implementation audit note, not a substitute for the Gazette or consolidated Rules.
